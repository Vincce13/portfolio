Court Booking & Admin System

A full booking platform for a sports court business — customers book hourly slots online, and admins manage everything from one dashboard: confirming or cancelling bookings, rescheduling, extending sessions, processing weather refunds, blocking slots for maintenance, and running "Open Play" group sessions with per-participant check-in.

  • Built the admin dashboard: booking status workflow (pending → confirmed → completed/cancelled/refunded), with grouped multi-hour bookings
  • Implemented a rain-refund calculator that pro-rates unused booking time by the minute
  • Built reschedule and hour-extension flows with real-time slot-conflict checks
  • Added a day-schedule view that merges bookings, blocked slots, and Open Play sessions into one hourly grid
  • Wired up automatic email notifications on status changes
